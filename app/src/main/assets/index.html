ربط الشيت (مرة واحدة)

  1. افتح الشيت واختار Extensions ثم Apps Script.
  2. امسح أي كود موجود والصق محتوى ملف apps-script.gs وبعدين Save.
  3. اضغط Deploy ثم New deployment واختار النوع Web app.
  4. خلّي Execute as: Me و Who has access: Anyone ثم Deploy، ووافق على الصلاحيات.
  5. انسخ Web app URL (بينتهي بـ /exec) والصقه هنا. لو عملته قبل كده للبرنامج على الكمبيوتر، استخدم نفس الرابط.
